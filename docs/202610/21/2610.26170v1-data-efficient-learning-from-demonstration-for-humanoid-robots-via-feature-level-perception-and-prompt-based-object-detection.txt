# Data-Efficient Learning from Demonstration for Humanoid Robots via Feature-Level Perception and Prompt-Based Object Detection 

Keyhan Rayati ∗, AliReza Beigy ∗, Anoosheh Saadati ∗, Pourya Shahverdi †,Mehdi Tale Masouleh ∗, Ahmad Kalhor ∗, Wing-Yue Geoffrey Louie †∗ Human and Robot Interaction Lab, University of Tehran, Tehran, Iran Emails: keyhan.rayati@ut.ac.ir, alireza.beigy@ut.ac.ir, anoosheh.saadati@ut.ac.ir, m.t.masouleh@ut.ac.ir, ahmad.kalhor@ut.ac.ir 

† Intelligent Robotics Laboratory, Oakland University, Rochester, Michigan, USA Emails: pourya.shahverdi@oakland.edu, geoff.louie@oakland.edu 

Abstract —Learning from Demonstration (LfD) allows robots to learn new skills from human examples; however, many vision-based methods require large datasets and resource-intensive end-to-end training. This paper introduces a data-efficient LfD framework for humanoid robots that learns manipulation skills from compact, task-specific features instead of raw images. The proposed approach integrates layered visual preprocessing, Kinect-based human joint estimation, prompt-based object detec-tion, and depth information to extract human motion features and three-dimensional object locations from demonstration videos. These features are used to train a temporal deep learning model that predicts robot joint-angle trajectories for execution. The framework is implemented on a NAO humanoid robot, evalu-ated quantitatively in simulation, and demonstrated on physical hardware. In simulation, the robot achieves a 78% success rate on a pick-and-place task using only 16 demonstrations, which increases to 86% when trained with 100 demonstrations. The framework also achieves a 71% success rate on a pushing task using eight demonstrations, highlighting its effectiveness for data-efficient humanoid skill acquisition. 

Index Terms —Humanoid robots, Learning from demonstra-tion, Robot manipulation, Feature-level perception, NAO robot, Object detection 

I. I NTRODUCTION 

Learning from Demonstration (LfD) offers an effective way for robots to acquire new skills through the observation of hu-man actions, rather than depending on explicitly programmed control policies. This is especially beneficial for humanoid robots, as creating task-specific controllers for manipulation is labor-intensive and difficult to generalize across different objects, environments, and users. Nonetheless, acquiring de-pendable humanoid manipulation skills from a limited number of demonstrations remains difficult due to perceptual noise, embodiment differences between humans and robots, and the restricted computational resources available on several humanoid platforms. LfD has been extensively studied for transferring human skills to robots, from traditional trajectory-based techniques such as Dynamic Movement Primitives to recent data-driven methods for robot skill learning from demonstrations [1]– [3]. Vision-based robot learning has also shown strong per-formance in manipulation, from spatial correspondence mod-els such as Transporter Networks [4] to large-scale visuo-motor policies such as RT-1 [5]. However, many of these methods still rely on raw visual inputs, large demonstration datasets, or considerable task-specific adjustment [4]–[7]. For humanoid robots, these challenges become harder because of embodiment differences, restricted joint limits, and the need to translate human motion and task structure into robot-executable trajectories [8]–[10]. Recent studies have explored more data-efficient learning from human videos and robot-free demonstrations, including keypoint-based representations, one-shot transfer, humanoid manipulation from human play videos, whole-body control from monocular videos, and mo-bile manipulation from robot-free demonstrations [11]–[15]. Still, learning robust humanoid manipulation skills from only a few task demonstrations remains difficult, especially when the perception and policy learning stages are trained directly from visual data. This motivates the feature-level approach used in this work, where prompt-based object detection, depth information, and skeleton-based motion features are extracted before training the robot trajectory model. This research introduces a data-efficient LfD framework for humanoid robots that acquires manipulation skills using compact state representations rather than raw images. The proposed approach extracts task-relevant information from human demonstration videos, including human joint positions, prompt-detected objects, and depth-based three-dimensional object locations. Prompt-based object detection localizes task objects without requiring a task-specific detector, while skele-ton tracking provides human motion data for estimating robot joint trajectories. The collected features are then used to train a task-specific temporal model that predicts joint-angle commands for execution on a NAO humanoid robot. The framework is assessed quantitatively in simulation and demonstrated on real hardware, including upper-body imita-tion and two manipulation tasks: pick-and-place and object pushing. In the simulated pick-and-place task, the robot attains arXiv:2610.26170v1 [cs.RO] 19 Oct 2026 a success rate of 78% with 16 demonstrations and 86% with 100 demonstrations. The framework also attains a 71% success rate in the pushing task with only eight demonstrations. These results suggest that feature-level perception can facilitate hu-manoid skill acquisition with limited demonstration resources. The primary contributions of this work are summarized as follows:  

> •

A data-efficient LfD framework is provided for humanoid manipulation using compact state representations instead of raw image-based policy learning.  

> •

A layered perception pipeline is established to inte-grate Kinect-based skeleton tracking, prompt-based ob-ject detection, and depth data for extracting task-relevant demonstration features.  

> •

A temporal prediction model with explicit step and task-state embeddings is used to condition progress during autoregressive joint-trajectory rollout.  

> •

The framework is evaluated on a NAO humanoid robot through quantitative simulation experiments and repre-sentative real-world demonstrations, showing upper-body imitation, pick-and-place, and pushing actions with lim-ited demonstration data. 

Supplementary Material: A video demonstration of the proposed framework is available online [Video]. The code implementation is available online [Code]. II. P ROPOSED FRAMEWORK 

The proposed framework learns robot arm trajectories from human demonstration videos using a compact feature repre-sentation rather than raw image sequences. As illustrated in Fig. 1, the pipeline consists of demonstration capture, feature extraction, temporal model training, and robot execution. RGB images, depth information, and human skeletal joint positions are captured using a Kinect camera as a person performs the task. Task-relevant objects are localized using YOLO-World prompt-based object detection [16], with categories such as “red ball”, “green box”, or “block” provided as textual prompts. The detected image-space coordinates are matched with Kinect depth data and the camera model to estimate three-dimensional object positions. Human joint positions are derived from the Kinect skeleton stream and converted into joint-angle features suitable for the target robot motion. The same perception and learning framework is used across tasks; however, the trajectory model is trained separately for each manipulation objective. 

A. Feature Extraction 

The feature vector at each timestep combines human arm configuration, prompt-detected object positions, task state, and progress information. Human joint localization is obtained from the Kinect Skeleton API, with all joint positions ex-pressed in the Kinect camera coordinate frame. Building on prior NAO motion-transfer work [17], the measured human arm geometry is converted into robot-compatible joint-angle features. All input and output variables are normalized before training so that object coordi-nates and joint angles have comparable numerical scales and remain within NAO joint limits during execution. 

B. Temporal Model 

The temporal model predicts robot joint angles from a fixed-length sequence of feature vectors. As depicted in Fig. 2, a Long Short-Term Memory (LSTM) layer captures short-term motion dependencies over an input window of 10 timesteps. Two supplementary embedding layers encode the current ex-ecution step and a three-valued grasp/task state representing the manipulation phase. The LSTM output and embeddings are concatenated and passed through a fully connected output layer with linear activation to predict continuous robot joint angles. The explicit step embedding provides a progress indicator during autoregressive rollout. During deployment, the model repeatedly predicts the next joint configuration and incor-porates the resulting state into the following input window. Without such a signal, recurrent models trained on limited datasets may remain near familiar states or cycle through incomplete motions. The step index provides a clear indication of execution progress, while the LSTM focuses on the rela-tionship among current features, object positions, and joint trajectories.

The framework is evaluated in simulation and on a physical NAO robot. The experiments examine whether the proposed feature-level model can support humanoid imitation and ma-nipulation from limited demonstrations. Three scenarios are considered: upper-body imitation, pick-and-place, and object pushing. In the manipulation experiments, a trial is considered successful when the robot completes the task objective without leaving the feasible workspace: placing the ball in the box for pick-and-place, or moving the block in the specified direction for pushing. 

A. Upper-Body Imitation 

The upper-body imitation experiment confirms that Kinect-based joint localization and human-to-robot angle mapping, building on previous NAO motion-transfer research [17], can produce feasible NAO arm motion. Human subjects perform arm movements in front of the Kinect camera, and the derived joint angles are transformed into NAO commands. Preliminary assessments are performed in Choregraphe to ensure motion safety before executing the commands on physical hardware. As illustrated in Fig. 3, the robot reproduces representative arm configurations through coordinated shoulder and elbow move-ments. This experiment validates that the feature extraction process provides a viable basis for the manipulation studies.

B. Pick-and-Place 

The primary manipulation task is to place a red ball into a green box. Demonstrations are recorded with variations in the initial positions of the ball and box. The initial low-data setting contains 16 videos collected from two participants. For comparison with larger-data settings, an additional dataset of 100 demonstrations is collected with varied object place-ments within the robot workspace. The same preprocessing and model architecture are used in both settings. The 16-video dataset was gathered in two stages, with eight initial demonstrations followed by eight additional demonstrations using different object locations. The CoppeliaSim evaluation environment is shown in Fig. 4. Fig. 4. CoppeliaSim configuration for the pick-and-place task, with the NAO robot moving a red ball into a green box. 

In simulation, the proposed framework achieves a 78% success rate with only 16 demonstrations and an 86% success rate with 100 demonstrations. Table II presents these results alongside relevant baselines from a related pick-and-place benchmark in Transporter Networks [4]. Because the tasks, robots, and sensing assumptions are different, this comparison is intended as a contextual data-efficiency reference rather than a controlled head-to-head benchmark. The comparison sup-ports the data-efficiency motivation for using compact object and motion features rather than learning a policy directly from raw images. Physical robot trials are performed with the box positioned on both sides of the ball and with distracting objects visible in the camera field of view. These trials are used to verify real-world feasibility of the perception and execution pipeline rather than to provide a full statistical sim-to-real benchmark. The robot successfully completes representative physical ex-ecutions in both left-side and right-side placement configu-rations. Accordingly, quantitative success rates are reported for the controlled simulation experiments, while the physical trials demonstrate that the learned trajectories and prompt-based localization can be transferred to the NAO hardware in the tested settings. 

C. Pushing Task 

The framework is also evaluated on a pushing task to examine its applicability beyond pick-and-place. The robot must push a block either from right to left or from left to right. A total of eight demonstrations are collected, with four for each direction. The same preprocessing pipeline is used, with the block position included as an object feature. Two direction-specific models are developed because, unlike the pick-and-place task where the box defines the target, the pushing objective is determined by the specified direction. In the right-to-left configuration, the robot succeeds in 37 out of 50 trials. In the left-to-right configuration, it succeeds in 34 out of 50 trials. The findings suggest that feature-level perception can sup-port humanoid manipulation learning with limited demonstra-tion resources. Rather than learning both perception and con-trol from raw images, the framework uses existing perception modules to extract human joint positions, object locations, and task state. This compact state representation reduces the complexity of the temporal learning problem and supports adaptation across the tested variations in object placement. This method also has limitations. Kinect skeleton tracking may be inaccurate under occlusion or unusual arm positions, and detection failures can reduce the accuracy of the object state estimate. The quantitative pick-and-place comparison is simulation-based and contextual, while the physical robot trials demonstrate feasibility rather than broad robustness or a complete sim-to-real success-rate analysis. The current pick-and-place setup uses a magnetic attach-ment between the NAO hand and the ball. This design reduces grasping uncertainty and allows the experiments to focus on trajectory learning, object localization, and humanoid arm ex-ecution. Therefore, the reported pick-and-place results should not be interpreted as a full evaluation of dexterous grasping or general-purpose humanoid manipulation. Removing the mag-netic attachment would likely introduce additional grasping failures and requires a separate evaluation with a more realistic end-effector. The human-to-NAO motion mapping is also approximate because the human arm and the NAO arm have different kinematic structures, joint limits, and wrist capabilities. In particular, shoulder and elbow rotations may not map uniquely to the NAO 4-DOF arm, which can introduce end-effector pose uncertainty. In addition, validation loss was used as the main offline model-selection criterion, although task success may not always vary monotonically with prediction error. Future work should extend the framework to a wider range of manipulation skills, include task-level success in model selection, improve closed-loop correction during execution, and evaluate the method using more advanced sensors and dexterous end-effectors. V. C ONCLUSION 

This paper introduced a data-efficient LfD framework for humanoid robots based on feature-level perception and prompt-based object detection. The framework extracts hu-man motion and object-location features from demonstration videos, trains a temporal model to predict NAO joint trajec-tories, evaluates the learned skills in simulation, and demon-strates them on physical hardware. Experiments show success-ful upper-body imitation, simulated pick-and-place success rates of 78% using 16 demonstrations and 86% using 100 demonstrations, and a 71% success rate in pushing with eight demonstrations.
